# 终端界面（`catbus tui`）

不想记命令时，用全屏界面：选平台、选命令、填参数、看结果，还能在里面登录、切账号、监听直播弹幕。它和命令行共用同一份命令表，新增平台或命令后界面自动出现。

```bash
catbus tui
```

需要交互式终端（stdin 和 stdout 都是 TTY），窗口至少 80 × 24，窗口小了会提示放大，放大后自动恢复。在脚本或管道里运行会报 `USAGE`，退出码 2。

## 界面

窗口 ≥ 110 列时三栏并排：

| 栏 | 内容 |
|---|---|
| 平台 | 11 个平台和各自已实现的命令数。`●` 已登录，青色 `●` 免登录可用（12306），`○` 未登录 |
| 命令 | 按 resource 分组，`▾` 展开、`▸` 收起。每条命令前的标记见下表 |
| 参数 | 选中命令的说明、参数和选项。必填项带 `*`，枚举选项用 ← → 切换 |

窗口在 80 到 109 列之间时，参数表单盖在命令栏上，其余操作相同。

命令前的标记：

| 标记 | 含义 |
|---|---|
| `●` | 在界面里运行 |
| `~` | 持续监听（弹幕、私信），按 Enter 开始 |
| `○` | 界面里不运行，复制到终端执行（写入、删除、发布等） |
| `-` | 规划中，还没实现 |

界面底部始终显示**等价命令**。按 `c` 复制，可以直接贴到终端或交给 Agent 重放。

## 按键

| 键 | 作用 |
|---|---|
| `↑ ↓` 或 `j k` | 上下移动 |
| `→ ←` 或 `l h` | 展开、进入、收起、返回 |
| `Tab` | 换栏；在表单里换字段 |
| `Enter` | 展开命令、填完参数后运行 |
| `/` | 命令面板：输入平台名、中文说明或命令名，搜遍全部平台 |
| `a` | 账号页：切换、检查、登出、登录新账号 |
| `c` | 复制等价命令 |
| `T` | 切换浅色 / 深色配色（只在这次运行里生效） |
| `?` | 帮助 |
| `Esc` | 返回上一级 |
| `q` 或 `Ctrl-C` | 退出 |

结果页：

| 键 | 作用 |
|---|---|
| `Enter` | 接着做什么：评论、作者资料、监听……（见下） |
| `y` `o` | 复制链接 / 在浏览器打开 |
| `n` | 下一页（光标移到列表末尾附近也会自动取） |
| `J` | 看选中项的原始对象（等于 `--raw`） |
| `Esc` | 回到上一页结果；没有上一页就回首页 |

## 接着做什么

在结果页选中一项按 `Enter`，会列出同一平台里能拿它当参数的命令，参数已经填好：

- 一条作品：看评论、作者资料、作者的作品、相关推荐、媒体地址……
- 一个直播间：直播间信息、最近的弹幕、礼物列表，以及**监听弹幕**。
- 一趟 12306 车次：票价（`--from-no` 等选项从车次里带出来）、经停站。

选中即运行，`Esc` 回到上一页结果。小红书的链接带 `xsec_token`，所以用 URL 作参数；其他平台用 ID。

## 登录

按 `a` 进入账号页，再按 `n` 登录新账号。可以选方式（该平台支持哪些就列哪些）、起账号名（留空是当前账号或 `default`）、填手机号等字段。

- **扫码**：二维码画在界面里（黑码白底，不随主题变色，深色主题下也能扫）。按 `o` 用系统图片查看器打开 PNG，按 `r` 换一张码，`Esc` 取消。
- **短信 / 密码**：验证码和密码在界面里输入，密码显示成 `*`。
- **cookie**：从浏览器开发者工具复制后，用终端的粘贴快捷键粘进来。
- **浏览器授权**（即梦）：界面显示授权链接，按 `o` 在浏览器打开，授权后自动完成；`Esc` 取消时同时结束 `dreamina` 的等待。

窗口太小画不下二维码时，界面会告诉你需要多大的窗口，同时可以按 `o` 打开图片扫码。B 站、闲鱼的码比较大，需要的窗口也更大。

> 人机验证（B 站极验）需要在浏览器里完成时，界面会显示一个本地链接，在浏览器打开后自动继续。

账号页里还能：`Enter` 设为当前账号，`t` 在线检查登录态是否有效，`x` 登出（要再按 `y` 确认；平台支持时同时退出服务端）。

## 监听

直播间的 `live listen`、私信的 `msg listen` 在界面里显示成滚动的事件流：

- 右栏是统计：已收到多少条、已运行多久、`--duration` 的倒计时、最近 6 分钟每分钟的事件数。
- `1`–`5` 隐藏 / 显示弹幕、礼物、关注、进场、点赞；`Space` 暂停（暂停期间新事件照常收，只是不滚动，会提示有几条未读）；`↑↓` 回看。
- `Esc` 停止并回到上一个界面，和命令行里按 Ctrl-C 一样。
- 断线会自动重连；登录态失效、触发风控这类重连解决不了的错误，会停在页面上显示原因。

界面只保留最近 500 条。要完整录下来，用命令行：`catbus bilibili live listen <room> -o jsonl > events.jsonl`。

## 启动动画

猫巴士开进来、打出 `catbus`，不到 1 秒，任意键跳过。Windows 上默认不出现，`CATBUS_TUI_ANIMATE=1` 打开；`CATBUS_TUI_ANIMATE=0`、`NO_COLOR`、`CATBUS_TUI_ASCII` 下也不出现。

## 环境变量

| 变量 | 作用 |
|---|---|
| `CATBUS_TUI_THEME=light\|dark` | 强制浅色或深色配色。默认看 `COLORFGBG`，没有就用深色 |
| `CATBUS_TUI_ASCII=1` | 用纯 ASCII 的边框和标记（`+ - \|`、`* o`） |
| `CATBUS_TUI_ANIMATE=0\|1` | 启动动画和吉祥物动画。Windows 默认关，其余系统默认开 |
| `NO_COLOR=1` | 不使用颜色，用粗体和反色区分选中项。二维码除外：没有颜色就扫不出来 |

## 常见问题

**边框错位、竖线对不齐。** 部分中文环境的终端会把 `● ○ │ ─` 这类字符显示成两列宽（iTerm2 的 “Ambiguous characters are double-width” 选项，Windows Terminal 在东亚语言下也可能如此）。设 `CATBUS_TUI_ASCII=1`，或者关掉终端里的这个选项。

**浅色终端上文字发灰。** macOS 的 Terminal.app 和 Windows Terminal 不设置 `COLORFGBG`，catbus 判断不出背景色。设 `CATBUS_TUI_THEME=light`，或者进界面后按 `T`。

**复制没反应。** 复制优先走系统命令：macOS `pbcopy`，Windows `powershell` 的 `Set-Clipboard`，Linux `wl-copy`、`xclip`、`xsel`。都没有时发 OSC 52 转义序列，iTerm2、Windows Terminal、kitty 等支持，macOS 自带的 Terminal.app 不支持。真的复制不了时，状态栏会显示命令，手动选中即可。

**二维码扫不出来。** 终端字体的行距不是 1 时，二维码的方块之间会有缝，手机识别不了。这时按 `o` 用图片扫。窗口缩放过也会让码变形，`r` 换一张码重画。

**Windows 上闪烁。** Windows 控制台遇到占满整屏的画面会逐帧清屏重绘，所以 Windows 上默认限制帧率并关掉动画。用 Windows Terminal 或 PowerShell 7 体验最好。老的 Windows 控制台（没有 `WT_SESSION`）上转圈会用 `| / - \` 代替盲文点阵，因为它的字体没有盲文字形。

## 吉祥物

右下角是一只像素版的猫巴士：车身颠簸、轮毂上的肉垫在转、路面向后退，偶尔眨一下眼。车窗里坐着小红书红、B 站粉、抖音青三位乘客。终端不支持真彩色、设了 `NO_COLOR` 或 `CATBUS_TUI_ASCII` 时，换成文字版的 `( >ω_ )`。
