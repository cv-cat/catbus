# Web 面板

不想敲命令时，可以用 `catbus ui` 在浏览器里使用 catbus 的全部能力：搜索、浏览、点赞评论、发布、私信、直播监听、账号登录与设置。

## 启动

```bash
catbus ui
```

- 面板只在本机（`127.0.0.1`）的随机端口上启动，地址里带一段随机路径，只有拿到这个地址才能打开。
- 启动后会自动打开浏览器；没有打开时，复制终端里打印的地址即可。
- 在终端里按 Ctrl-C 关闭面板。关闭时，还在运行的任务（例如直播监听）会一起结束。

面板用的是本机 `~/.catbus` 里的登录态和配置，和在终端里执行完全一样。

## 使用

顶部导航可以进入首页、账号、任务、设置和环境检查。平台栏在左侧；窄屏下点左上角菜单按钮展开，选中平台或按 Esc 收起。明暗主题跟随系统设置。

1. 从首页或左侧平台栏选一个平台，查看可用功能。可以按文字查找，例如「评论」「下载」。
2. 选择要使用的功能，填写所需内容。必填项会标出来，固定的选项直接点选。
3. 点「运行」（或按 ⌘/Ctrl + Enter）。结果显示在旁边或下方，可以切换到「运行记录」和「原始数据」。
4. 结果里的对象可以点进下一步：从笔记进作者主页、从视频看评论、从车次看经停站。

表单下方的「在终端中运行」会显示对应的 catbus 命令，点「复制命令」可以在终端里执行相同操作。页面中的名称和提示使用日常用语，复制的命令仍保留准确的参数和取值。

## 登录

在平台页点「登录」，选择登录方式：

| 方式 | 在面板上怎么做 |
|---|---|
| 扫码 | 二维码直接显示在页面上，用手机 App 扫码确认 |
| 短信 | 先填手机号点「发送验证码」，收到后填验证码点「完成登录」 |
| 账号密码、导入登录信息、访问密钥、登录令牌 | 将密码、Cookie、API Key 或 Token 填进对应的输入框。这些内容不会显示在命令预览和任务记录里 |

同一平台可以登录多个账号，用「账号备注」区分。在「账号」页可以检查登录是否仍可使用、切换当前账号、退出登录。

## 危险操作

删除、撤回、投币等操作执行前会弹出确认框，写明要执行的命令。确认后才会真正执行；取消不会产生任何修改。

写操作遇到网络错误时，面板会显示「结果未知」：请求可能已经生效，先到平台上确认，再决定要不要重新执行。

## 任务

「任务」页按操作名称列出本次使用期间的记录。离开或刷新页面后，可以在这里找回结果。停止运行 catbus 后记录清空。

启动操作后会立即显示“运行中”。“运行记录”随时更新启动、连接和结束等进度，无需等待任务结束。实时接收的消息逐条显示在“结果”中，“运行记录”会同时显示已接收数量；尚未收到消息不代表任务没有启动。

只有长连接（直播、私信监听）和等待中的登录可以停止；其他命令一旦开始，就不能取消。

## 文件

发布、上传头像等需要本地文件的选项，可以点「选择文件」从浏览器选，也可以直接填本机路径或 URL。选的文件会先存到面板的临时目录，关闭面板时删除。

下载类命令默认保存到启动 `catbus ui` 时所在的目录，可以在「下载目录」里改。

## 设置

「设置」页可以修改默认代理地址、最长等待时间、各平台的代理，以及用于 YouTube、Discord 平台验证的浏览器位置。设置保存在 `~/.catbus/config.toml`，与 `catbus config set` 相同。见[配置与数据目录](configuration.md)。

结果页的「排查详情」和环境检查的「查看详情」保留错误信息与技术说明，需要排查问题时可以展开查看；「原始数据」保留 JSON 格式的完整结果。

## 限制

- 只能在运行面板的这台电脑上打开。不支持远程访问和多人共享；在 Docker 里使用时，需要自己做端口转发。
- 面板不保存任何数据：登录态、配置仍由 catbus 读写 `~/.catbus`，任务记录关闭即清空。
